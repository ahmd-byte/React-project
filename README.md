# Ferrari-Inspired React Portfolio

A premium, modern web application built with React, TailwindCSS v4, and DaisyUI v5, featuring a luxurious Ferrari-inspired design aesthetic.

## ✨ Features

- 🎨 **Ferrari-Inspired Design** - Luxurious dark theme with iconic Ferrari red accents
- ⚡ **Lightning Fast** - Built with Vite for instant HMR and optimized builds
- 🎭 **Modern UI** - Premium components with smooth animations and transitions
- 📱 **Fully Responsive** - Seamless experience across all devices
- 🌙 **Theme Switching** - Toggle between light and dark modes
- 🔔 **Toast Notifications** - Elegant centered notifications with custom styling
- 🎯 **Type-Safe** - Built with modern React patterns and best practices

## 🎨 Design System

### Color Palette
- **Ferrari Black** (`#0A0A0A`) - Primary background
- **Ferrari Grey** (`#1A1A1A`, `#2A2A2A`) - Secondary backgrounds
- **Ferrari Red** (`#DC0000`) - Primary accent color
- **Ferrari Gold** (`#D4AF37`) - Secondary accent
- **White** (`#FFFFFF`) - Primary text

### Typography
- **Font Family**: Inter (Google Fonts)
- **Style**: Bold, uppercase headings with generous letter-spacing
- **Hierarchy**: Clear visual hierarchy with text gradients

## 🚀 Tech Stack

- **Framework**: React 18.2.0
- **Build Tool**: Vite 5.0.0
- **Styling**: TailwindCSS 4.1.17
- **UI Components**: DaisyUI 5.5.5
- **Routing**: React Router DOM 6.14.1
- **Notifications**: React Hot Toast 2.5.0
- **Animations**: Framer Motion 10.12.16
